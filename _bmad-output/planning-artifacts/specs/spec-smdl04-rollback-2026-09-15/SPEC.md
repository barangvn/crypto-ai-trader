# SPEC — S-MDL-04 Rollback Eligibility Gate + Safe Restore Target Decision

## Why

PRD FR-040: The system SHALL support rollback to the prior Champion OR to a safe disabled/observe-only state when defined degradation thresholds are breached. PRD FR-041: Every model change SHALL be auditable with approver, rationale, evidence, timestamp, and prior-state snapshot. PRD FR-036: Registry SHALL record rollback predecessor. LIFECYCLE.md T4 (Challenger→Champion) PRECONDITION explicitly requires "rollback prepared" (S-MDL-03 SPEC L34 source-ref). S-CON-02C §2.6 F5 (L202-203): Champion→Challenger direct FSM transition is FORBIDDEN — rollback uses a separate `rollback_champion` registry command (L252) and a READONLY eligibility decision (S-MDL-04), with mutation deferred to S-MDL-05 (CAP-5). S-MDL-03 NG2 (L58-60) explicitly carved out rollback as out-of-scope for promotion gate. S-MDL-02 CAP-12 already propagates `rollback_strategy_ref` (S-CON-02C L299) as a typed nullable pointer on ChampionChallengerEvaluation. S-MDL-01 already stores predecessor pointer (L98) but left predecessor selection + eligibility matrix OPEN. This story closes that open gap (source-backed only) to produce a deterministic, fail-closed, READONLY RollbackEligibilityDecision with explicit integration boundary against S-MDL-03 (no recalc), strict CAP-5 no-mutation, and 10× reproducibility per AD-20/NFR-007.
